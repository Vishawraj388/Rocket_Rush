# 🚀 Rocket Rush

Rocket Rush is a 3D physics-based rocket navigation game developed in Unity. The objective is to carefully pilot the rocket through increasingly challenging levels, avoid obstacles, and safely reach the finish platform.

## 🎮 Gameplay

* Control the rocket using thrust and rotation.
* Navigate through obstacles without crashing.
* Complete all three levels to win the game.
* Includes sound effects, particle effects, and a final victory screen.

## 🛠️ Built With

* Unity 6
* C#
* Unity Input System
* TextMeshPro
